# AI-Expense-Advisor Capstone Project

An enterprise-grade personal finance application powered by Claude SDLC agents.

## Features
- **US-001**: Transaction Ingestion pipeline (CSV parsing, normalization, automatic categorization).
- **US-002**: Budget Alerts & RAG Advisor (Real-time threshold monitoring and semantic search over personal expense history & financial guides).

## Getting Started
1. Copy `.env.example` to `.env` and fill in your credentials.
2. Review SDLC instructions in `CLAUDE.md`.
