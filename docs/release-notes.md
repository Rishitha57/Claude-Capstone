# Release Notes

## AI-Expense-Advisor - Initial SDLC Foundation

### Included

- US-001 CSV, JSON, and Plaid-style transaction normalization.
- Resilient handling for empty input, malformed JSON, invalid records, and invalid amounts.
- Optional idempotent Confluence publishing for SDLC artifacts.
- Requirements, architecture, design review, implementation plan, test report, and workflow audit documentation.
- Unit, integration, and end-to-end verification coverage.

### Not Included

- US-002 budget alerts and RAG advisor implementation.
- Production authentication, persistence, tenant isolation, and deployment infrastructure.
- Live Confluence tenant verification.
