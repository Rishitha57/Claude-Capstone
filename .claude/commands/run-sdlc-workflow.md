# Command: /run-sdlc-workflow

Execute the end-to-end SDLC workflow for the AI-Expense-Advisor capstone project.

## Execution Steps:
1. **Analysis & Architecture**: `sage-business-analyst` and `nexus-solution-architect` validate US-001 and US-002 specifications.
2. **Engineering & Branching**: `aria-solution-engineer` and `branch-git-planner` set up feature branches and technical specs.
3. **Implementation**: `forge-developer` implements ingestion parsers and RAG vector search.
4. **Testing & Review**: `shield-automation-tester` runs test suites; `lens-code-reviewer` reviews code quality.
5. **Deployment & Audit**: `deploy-build-engineer` builds artifacts; `chronicle-auditor` generates `docs/workflow-report-WF-2026-001.html`.
